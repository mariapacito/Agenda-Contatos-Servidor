# 📒 Agenda de Contatos

## 📌 Sobre o Projeto

O Agenda de Contatos é uma aplicação desenvolvida para facilitar o cadastro, a consulta, a edição e a exclusão de contatos pessoais e profissionais.

O projeto está sendo desenvolvido em conjunto pelas disciplinas de **PTAC e PTAS3**, com o objetivo de criar uma aplicação web para o gerenciamento de contatos, utilizando os conhecimentos adquiridos nas duas disciplinas.

## 🎯 Objetivo

Desenvolver uma API REST para gerenciar contatos, permitindo realizar operações CRUD (criar, consultar, atualizar e excluir) de forma simples e organizada.

## ⚙️ Funcionalidades

- Cadastrar contatos;
- Listar todos os contatos;
- Consultar um contato específico;
- Editar informações dos contatos;
- Excluir contatos;
- Validar os dados enviados à API.

## 🛠️ Tecnologias Utilizadas

- Node.js
- Express
- Zod
- JavaScript
